## 1. Overview
The design foundation leverages the existing MINDVERSE glassmorphic design system (`GlassContainer`, `AppCard`, `AppButton`, `AppColors`, `AppTypography`). A modular `SocialLinkTile` component will be established to handle external icon links, clipboard copy actions, and visual feedback.

---

## 2. Design Foundation Elements
- **Color Tokens:** Utilizing `AppColors.primary`, `AppColors.surfaceCard`, `AppColors.borderSubtle`, and system glass fill.
- **Typography:** `AppTypography.titleLarge` for section headers, `AppTypography.bodyLarge` for descriptions, and `AppTypography.labelSmall` for badges/captions.
- **Component Architecture:** Reusable `SocialLinkTile` widget supporting icon, label, subtitle/handle, action button (e.g. "Copy" or "Open"), and success toast feedback.
